Esta página no tiene backend propio cuando está publicada en GitHub Pages, así que para guardar una sesión usa un pequeño servidor intermediario (un Worker de Cloudflare) que es el único lugar que conoce el token real de GitHub. Vos solo necesitás la URL de ese servidor y la clave del grupo — ninguna cuenta de GitHub. Guardá lo que pegues acá y compartí con tus amigos únicamente la URL y la clave (nunca por acá, por chat/WhatsApp entre ustedes).
